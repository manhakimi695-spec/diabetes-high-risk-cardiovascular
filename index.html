💊 Medication Class Overview

Understand how each drug class helps manage cardiovascular risks.

Biguanide

Reduces liver glucose production.

Drugs: Metformin, Metformin XR, Metformin SR

SGLT2 Inhibitors

Helps kidneys remove glucose.

Drugs: Dapagliflozin, Canagliflozin, Empagliflozin, Luseogliflozin, Ertugliflozin

GLP-1 receptor agonists

Mimics incretin hormones.

Drugs: Exenatide IR, Exenatide ER, Dulaglutide, Liraglutide, Lixisenatide, Semaglutide

DPP-4 Inhibitors

Maintains natural incretins.

Drugs: Sitagliptin, Vildagliptin, Saxagliptin, Linagliptin

Sulfonylureas (SU)

Stimulates insulin release.

Drugs: Glibenclamide, Gliclazide, Gliclazide MR, Glipizide, Glimepiride

Insulin Therapy

Standard insulin replacement.

Drugs: Lantus, Basalog, Toujeo, Levemir, Tresiba, Novomix, Humalog Mix25, Humalog Mix50
